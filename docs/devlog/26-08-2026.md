## Adicionar Continous Integration

Oque eu queria implementar?

Eu basicamente queria adicionar o CI no meu projeto, rodando testes e verificar as formatacoes do projeto sempre que um push ou pull request for feito na main.

## Oque foi feito

FOi implementado o primeiro workflow do CI e configurei o Ruff e Pytest no GitHub Actions.

## Dificuldades

As principais dificuldades não foram nem a parte de escrever o CI em si, mas sim na parte de definir as variaveis de ambiente dentro do git e depois adiciona-lás dentro do arquivo do CI. Passei muito tempo tentando entender qual era o erro (NotImplementedError), porém se tratava apenas da forma como eu estava definindo as variáveis dentro do GitHub secrets (com aspas). Outra dificuldade, foi que eu não estava colocando as variaveis de banco de dado no github, por segurança e porque também eu não iria utiliza-lás nos testes, dando erro de validação do pydantic no settings, pois os valores precisavam ser alimentados.

## Como resolvi

Como se tratava apenas na forma de adicionar os segredos, eu apenas retirei as aspas que lá havia, e os testes passaram. Para resolver o erro no pydantic, eu apenas alimentei o settings com variaveis falsas, ja que nao utilizaria para nada.

## Oque eu aprendi

Conseguir entender melhor um pouco de como se constroe um Continous Integration utilizando o GitHub Actions.
