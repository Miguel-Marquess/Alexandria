# 10-09-2026

## Adicionar type hint em todo o projeto

### Oque eu queria implementar?

Queria deixar o projeto mais profissional e facilitar a leitura implementando os type hints do python, deixando o projeto tipado (claro que somente pra documentação e para melhorar o entendimento).

## Oque foi feito

Foi adicionado dicas de tipo em toda funcao do projeto, desde endpoints ate testes.

## Dificuldades

As principais dificuldades foi apenas entender melhor como funciona os tipos em python (descobrindo tipos novos como Callable, Any, Generator, além de funções como cast), e principalmente conseguir deixar as funcionalidades mais explicitas (devido ao mypy), pois sempre dava conflito entre o mypy, e as abstrações do sqlalchemy, factoryboy, pydantic, pytest e etc.

## Como resolvi

Para resolver a parte do pydantic, apenas instalei um plugin no mypy que ajudava a reconhecer as abstrações dele. Além disso, tive que remover ou modificar funções que ja existiam dentro do projeto pra que ficasse mais explicito oque a função fazia ou retornava. E para a parte do FactoryBoy, eu comecei a utilizar a função cast, que "transforma o tipo de um objeto em outro".

## Oque eu aprendi

Aprendi a entender melhor os type hints do python além de ganhar o costume de adicioná-los desde sempre.
